# Resuena landing

Static one-page site for resuenapr.com. No build step.

- Edit sources: the SOURCES object at the bottom of index.html (numbers + scrolling names update automatically).
- Pilot form: set FORM_ENDPOINT in index.html; until then it opens an email draft to hola@resuenapr.com.
- Vercel: framework Other, no build command, domain resuenapr.com.
